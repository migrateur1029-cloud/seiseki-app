2ch成績表

YouTube チャンネルの運営者本人が、自分のチャンネルを管理するために使う道具です。一般の方に配っている物ではありません。

できること

  • 運営者自身のチャンネルと動画の成績（再生数・視聴時間・クリック率など）を YouTube から読み取り、運営者のパソコンの中に表として記録します。
  • 運営者自身の動画が公開された時に、運営者があらかじめ用意したコメントを、そのチャンネルとして投稿します。

使っている仕組み

Google の YouTube Data API と YouTube Analytics API を使います。運営者が Google アカウントで許可した範囲だけを使い、許可はいつでも取り消せます。

プライバシーポリシー

About (English)

"2ch成績表" is a private tool used only by the owner of the YouTube channels to manage their own channels. It reads the analytics of the owner's own channels and videos and stores them on the owner's computer, and posts comments prepared by the owner on the owner's own videos when they are published. It uses the YouTube Data API and the YouTube Analytics API. It is not offered to the public.
